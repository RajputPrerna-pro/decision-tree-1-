# 🌳 Decision Tree Machine Learning Projects

This repository contains machine learning projects based on **Decision Tree algorithms** using Python and Scikit-learn.

## 📌 Projects Included

### 1. Decision Tree Regression

The **Decision Tree Regression** project demonstrates how a Decision Tree Regressor can be used to predict a continuous target value.

**Technologies Used:**

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

**Steps Covered:**

* Data loading
* Data preprocessing
* Exploratory data analysis
* Train-test split
* Decision Tree Regression model
* Model training
* Prediction
* Model evaluation

📁 Project folder: `2decision tree in regression`

---

### 2. Loan Approval Prediction

This project uses machine learning to predict whether a loan application is likely to be approved based on applicant information.

**Technologies Used:**

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook

**Steps Covered:**

* Dataset loading
* Data preprocessing
* Feature selection
* Train-test split
* Decision Tree model
* Model training
* Prediction
* Model evaluation

📄 Dataset: `loan_approval_dataset.csv`
